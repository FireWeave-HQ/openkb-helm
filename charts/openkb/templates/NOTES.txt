{{- else }}

Authentication is enabled. The bearer token is not printed here.
{{- if .Values.auth.existingSecret }}
It is key {{ .Values.auth.tokenKey }} in Secret {{ .Values.auth.existingSecret }}.
{{- else }}
It is key OPENKB_API_TOKEN in Secret {{ include "openkb.fullname" . }}.
{{- if not .Values.auth.token }}
Helm generated that token and will reuse it on upgrade only when the upgrade can read the cluster (`lookup`). `helm template` and `helm upgrade --dry-run=client` mint a new value every time. Do not apply that output over this release. For a stable token, set auth.existingSecret or auth.token.

{{- end }}

  kubectl get secret -n {{ .Release.Namespace }} {{ include "openkb.secretName" . }} -o jsonpath='{.data.{{ include "openkb.tokenKey" . }}}' | base64 -d && echo

Send it as `Authorization: Bearer <token>`. The Workbench asks for it once and stores it in the browser.
{{- end }}

Knowledge bases are stored at {{ include "openkb.kbRoot" . }} on volume {{ include "openkb.claimName" . }}.
{{- if not .Values.persistence.enabled }}
persistence.enabled is false, so that path is an emptyDir and knowledge bases are deleted when the Pod is deleted.
{{- else if .Values.persistence.existingClaim }}
The chart uses existing claim {{ .Values.persistence.existingClaim }} and will not delete it.
{{- else }}
The PVC is named {{ include "openkb.claimName" . }} and is annotated helm.sh/resource-policy: keep.
`helm uninstall` does not delete it. To delete the knowledge base data:

  kubectl delete pvc -n {{ .Release.Namespace }} {{ include "openkb.claimName" . }}
{{- end }}

{{- if and (gt (int .Values.replicaCount) 1) .Values.persistence.enabled (has "ReadWriteOnce" .Values.persistence.accessModes) }}

WARNING: replicaCount is {{ .Values.replicaCount }} and the volume is ReadWriteOnce.
Only one Pod can mount it. Keep replicaCount at 1, or switch to ReadWriteMany and set updateStrategy.type to RollingUpdate.
{{- end }}
