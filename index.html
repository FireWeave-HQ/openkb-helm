OpenKB Helm Chart

Deploy OpenKB on Kubernetes

This is a community Helm chart for OpenKB, the Open LLM Knowledge Base by VectifyAI. It deploys the OpenKB REST API and the Knowledge Workbench web UI. Knowledge bases live on a PersistentVolumeClaim, LLM keys live in a Kubernetes Secret, and bearer-token authentication is on by default.

Install

helm repo add openkb https://fireweave-hq.github.io/openkb-helm
helm repo update
helm install openkb openkb/openkb --namespace openkb --create-namespace

Upstream does not publish a container image. Build the included Dockerfile, push it to your registry, and set image.repository. The full guide is in the README.
